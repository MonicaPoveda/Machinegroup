A virtual agent learns, through trial and error, to navigate a 10×10 grid from the start cell to the target while avoiding walls and minimizing time spent in danger zones.

Reward System

Every action the agent takes returns a reward. Small negative rewards discourage wasted movement, larger negative rewards discourage unsafe or invalid moves, and a large positive reward marks success.

Situation Reward Purpose
Moving to a valid normal position {{ rewards.normal }} Small penalty per step so the agent prefers shorter routes.
Attempting an invalid movement (outside the grid) {{ rewards.invalid }} Discourages trying to leave the boundaries of the grid.
Hitting a wall {{ rewards.wall }} Teaches the agent that walls are impassable obstacles.
Entering a Danger Zone {{ rewards.danger }} The move is allowed, but the strong penalty teaches the agent to avoid danger zones when a safer path exists.
Reaching the goal +{{ rewards.goal }} Large positive reward that reinforces the sequence of actions leading to success.

Environment Logic

For every action, the environment resolves current state → selected action → next state → cell type → reward → episode end. The 4 possible actions (Up, Down, Left, Right) always move the agent by one cell in the corresponding direction.

Outside the grid or into a wall

The move is rejected: the agent stays in its current state and receives the "invalid" or "wall" penalty.

Into a Danger Zone

The move succeeds — the agent occupies the danger cell — but it receives the danger penalty.

Into a normal path cell

The move succeeds with the standard step penalty, and the episode continues.

Reaching the Target

The agent receives the goal reward and the episode ends immediately.

An episode also ends if the agent reaches the maximum number of allowed steps ({{ max_steps }}) without reaching the target.

Q-Learning Implementation

Q-values are estimated with an incremental linear model (SGDRegressor) instead of a lookup table: predict() estimates the Q-value of each action for a given state, and partial_fit() updates the model after every single step using the observed reward and the best estimated Q-value of the next state.

The model is never told the correct route in advance — the final evaluated path is entirely a product of the Q-values learned from repeated interaction with the environment.

Exploration & Exploitation

The agent follows an Epsilon-Greedy strategy: with probability ε it explores (a random action, to discover the environment), and with probability 1-ε it exploits (the action with the highest estimated Q-value). ε starts high so the agent explores freely, and decays after every episode so the agent increasingly relies on what it has learned.
