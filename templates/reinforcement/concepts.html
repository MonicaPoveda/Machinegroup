What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of Machine Learning in which an agent learns to make decisions by interacting with an environment.

Unlike supervised learning, there are no labeled examples. Instead, the agent learns from rewards and penalties received after each action. The goal is to learn a policy that maximizes the total reward over time.

The agent is a virtual robot navigating a 10×10 maze. It must learn the best path from the start to the goal while avoiding walls and danger zones.

Types of Learning

Supervised

Learns from examples that include a known answer. Example: classifying emails as spam or not spam.

Unsupervised

Identifies patterns without labels. Example: grouping customers by behavior.

Reinforcement

Learns sequential decisions through interaction and rewards.

Core Concepts

Agent

The learner or decision-maker. In our exercise, the agent is the virtual robot navigating the maze.

Environment

Everything the agent interacts with. In our exercise, the environment is the 10×10 maze with walls and danger zones.

State

The current situation of the agent. In our exercise, the state is the current row and column of the agent in the maze.

Action

The decision made by the agent. The four possible actions are: Up, Down, Left, Right.

Rewards and Penalties

Positive feedback received after an action. In our exercise, the agent receives +20 when it reaches the goal.

Negative feedback received after an action. In our exercise:
  • -1 for a valid normal movement
  • -5 for hitting a wall or invalid movement
  • -10 for entering a Danger Zone

The reward received right after taking an action. It helps the agent learn which actions are good in each state.

The total discounted reward accumulated over an episode. It is calculated as:
Return = R₁ + γR₂ + γ²R₃ + ...
where γ is the discount factor.

Learning Process

Policy

The strategy used by the agent to choose actions based on the current state. The goal of RL is to find the optimal policy.

Episode

A complete sequence of actions from the start state until the agent reaches the goal or the maximum number of steps is reached.

Step

A single interaction between the agent and the environment: state → action → next state → reward.

Experience

The information collected by the agent: (state, action, reward, next state). It is used to update the Q-values.

Exploration vs Exploitation

Exploration

Trying new actions to discover the environment. This helps the agent find better paths it might not know yet.

Exploitation

Using the best-known action to maximize reward. This helps the agent refine its policy.

Epsilon-Greedy Strategy

A common strategy to balance exploration and exploitation:

  • With probability ε (epsilon), the agent explores (random action).
  • With probability 1 - ε, the agent exploits (best-known action).

Q-Learning

Q-Learning is a model-free RL algorithm that learns the value of taking an action in a given state.

State Value V(s)

The expected return starting from state s. It represents how good it is to be in a particular state.

Action Value Q(s,a)

The expected return when taking action a in state s. It represents how good it is to take a specific action in a given state.

Discount Factor (γ)

A value between 0 and 1 that determines the importance of future rewards. A value close to 1 means the agent values long-term rewards; a value close to 0 means it only cares about immediate rewards. In our exercise, we use γ = 0.95.

Q-Learning Update Rule

Q(s, a) ← Q(s, a) + α [r + γ · max Q(s', a') - Q(s, a)]

Where α is the learning rate, r is the reward, γ is the discount factor, and s' is the next state.
