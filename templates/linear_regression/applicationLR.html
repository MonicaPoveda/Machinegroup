Problem Context

The time required to download a file is not always the same. It can vary depending on characteristics of the file and the conditions under which the download takes place. In this application, we focus specifically on the relationship between the size of a file and the time required to download it.

The dataset contains historical observations in which each record associates a file size, measured in megabytes, with the corresponding download time, measured in seconds. These observations provide the information required for the Machine Learning model to learn the existing relationship between both variables.

Purpose of the application

The purpose of applying Simple Linear Regression is to use the historical data to learn a linear relationship between file size and download time. Once trained, the model can estimate the expected download time for a new file size.
