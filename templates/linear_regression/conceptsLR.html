What is Linear Regression?

Linear Regression is a statistical technique used to examine the relationship between variables and predict continuous numerical outcomes. In Machine Learning, the model learns this underlying structure from observed data to estimate unknown target values.

Core Takeaway

The objective is to identify the best-fit straight line representing historical observations, enabling precise predictions for unseen inputs.

Scatter plot showing observed data and the fitted regression line.

What Problems Can It Solve?

Applicable whenever the target variable is continuous and numerical.

Continuous Value Forecasting Predict quantities such as real estate prices, revenue, temperature, energy consumption, or test scores.
Data-Driven Estimation Leverages historical features to approximate unobserved numeric parameters accurately.
Feature Relationship Analysis Quantifies the magnitude and direction of influence one attribute exerts over another.
When is it unsuitable? If the target variable is categorical (e.g., "spam" vs. "not spam"), classification algorithms must be used instead.

Independent and Dependent Variables

Prior to training a model, two primary components must be defined: the input features (known data) and the target variable (the numeric output to predict).

X

Independent Variable (Features)

The input metrics provided to the system. They serve as the baseline predictor. In Multiple Linear Regression, additional inputs are expressed as X₁, X₂, X₃…

y

Dependent Variable (Target)

The calculated outcome that depends on input X. It represents the target attribute estimated during inference.

Relationship Between Variables

This metric describes how the dependent variable (y) responds to adjustments in the independent variable (X).

Linear Regression assumes an underlying approximately linear association. Consequently, unit changes in X correspond to proportional upward or downward trends in y that can be modeled via a straight line.

Example

If X represents dedicated study hours and y indicates academic performance, higher study hours generally correspond to improved grades.

Positive Relationship

As X increases, y tends to increase proportionally.

Negative Relationship

As X increases, y tends to decrease proportionally.

No Linear Relationship

No distinct linear trajectory is observed between X and y.

The Regression Line

Model optimization takes place during this stage. The algorithm systematically evaluates combinations of slope and intercept to identify the line that minimizes variance across all sample points.

Optimization is driven by the Ordinary Least Squares (OLS) method. OLS computes individual residual errors, squares them to eliminate directional sign cancelation, and aggregates the total sum. Minimizing this aggregated metric—known as the Cost Function—yields the optimal fit.

y = mX + b

m (Slope): The rate of change in y per unit change in X.
b (Y-Intercept): The value of y when X equals 0.

Visual representation of the fitted regression line minimizing error residuals.

Prediction and Inference

Upon completing training and securing optimal parameters for m and b, inference involves evaluating y = mX + b for novel input values.

Extrapolation Risk Notice

Model performance is reliable primarily within the range of training inputs. Generating estimations for domain values far beyond historical boundaries (e.g., studying 40 consecutive hours) introduces extrapolation risk, as real-world constraints often deviate from linear assumptions outside known bounds.
