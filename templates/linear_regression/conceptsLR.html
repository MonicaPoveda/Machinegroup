What Is Linear Regression?

Linear Regression is a statistical technique used to examine the relationship between variables and predict continuous numerical outcomes. In Machine Learning, the model learns this underlying structure from observed data to estimate unknown target values.

Core Takeaway

The objective is to identify the best-fit straight line representing historical observations, enabling predictions for unseen inputs.

Scatter plot showing observed data and the fitted regression line.

What Problems Can It Solve?

Applicable whenever the target variable is continuous and numerical.

Continuous Value Forecasting Predict quantities such as real estate prices, revenue, temperature, energy consumption, or test scores.
Data-Driven Estimation Leverage historical features to approximate unobserved numerical values.
Feature Relationship Analysis Analyze the magnitude and direction of the relationship between numerical variables.
When Is It Unsuitable? If the target variable is categorical, such as "spam" versus "not spam", classification algorithms should be used instead.

Independent and Dependent Variables

Before training a model, two primary components must be defined: the input features (known data) and the target variable (the numerical output to predict).

X

Independent Variable

Features

The input metrics provided to the system. They serve as the baseline predictors. In Multiple Linear Regression, additional inputs are expressed as X₁, X₂, X₃, and so on.

Y

Dependent Variable

Target

The numerical outcome that depends on input X. It represents the target value estimated during prediction.

Relationship Between Variables

This relationship describes how the dependent variable (Y) responds to changes in the independent variable (X).

Linear Regression assumes an underlying approximately linear association. Consequently, changes in X can correspond to upward or downward trends in Y that can be represented using a straight line.

Example

If X represents dedicated study hours and Y indicates academic performance, higher study hours may generally correspond to improved grades.

Positive Relationship

As X increases, Y tends to increase.

Negative Relationship

As X increases, Y tends to decrease.

No Linear Relationship

No distinct linear pattern is observed between X and Y.

The Regression Line

Model optimization takes place during this stage. The algorithm evaluates possible combinations of slope and intercept to identify the line that best represents the observed data.

Optimization is driven by the Ordinary Least Squares (OLS) method. OLS calculates residual errors, squares them to avoid directional cancellation, and minimizes the resulting total error to obtain the best fit.

y = mX + b

m (slope): the rate of change in Y per unit change in X.
b (Y-intercept): the value of Y when X equals 0.

Visual representation of the fitted regression line minimizing error residuals.

Prediction and Inference

After training the model and obtaining optimal parameters for m and b, inference involves evaluating the equation y = mX + b for new input values.

Extrapolation Risk Notice

Model performance is primarily reliable within the range of the training inputs. Generating estimations far beyond historical boundaries, such as studying 40 consecutive hours, introduces extrapolation risk because real-world behavior may not continue following the same linear pattern.
