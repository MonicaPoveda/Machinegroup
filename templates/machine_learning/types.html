Types of Machine Learning

Discover the three main types of machine learning, their characteristics, and real-world applications.

Supervised Learning

The model learns from labeled data, where the target variable or outcome is known.

Classification Regression
📌 Key Characteristics:
  • Requires labeled training data
  • Predicts values or categories
  • Evaluated with error metrics
  • Used for risk assessment, image recognition, predictive analytics, and fraud detection
💡 Common Algorithms:
Linear Regression Random Forest Logistic Regression SVM Naïve Bayes Neural Networks
📊 Example:
  • Spam email detection
  • House price prediction
  • Image recognition
  • Credit risk assessment

Unsupervised Learning

The model finds hidden patterns in unlabeled data without predefined outcomes.

Clustering Association
📌 Key Characteristics:
  • Works with unlabeled data
  • Discovers hidden structures
  • Reduces dimensionality
  • Enables exploratory data analysis and pattern recognition
💡 Common Algorithms:
K-Means Hierarchical PCA Apriori Gaussian Mixture
📊 Example:
  • Customer segmentation
  • Social network analysis
  • Recommendation systems
  • Anomaly detection

Self-Supervised Learning

Models learn from unlabeled data by automatically generating labels from the input itself.

Predictive Pretext Tasks
📌 Key Characteristics:
  • Learns from unlabeled data without human annotation
  • Generates labels automatically from input data
  • Transforms unsupervised problems into supervised ones
  • Particularly useful for computer vision and NLP tasks
💡 Common Applications:
Computer Vision Natural Language Processing Language Models Image Generation
📊 Example:
  • Masked Language Modeling (BERT)
  • Image rotation prediction
  • Contrastive learning (SimCLR)
  • GPT models

Semi-supervised learning

Semi-supervised learning is a machine learning technique that combines labeled and unlabeled data to train a model.

The main idea is to take advantage of a small amount of data where we know the correct answer and a large amount of data where we don't have labels.

Limited Labels Data Efficiency
📌 Key Characteristics:
  • Combines labeled and unlabeled data
  • It reduces the need to label data
  • Take advantage of large amounts of information
  • Improves model performance
  • It is useful when labeling is difficult or expensive.
  • Utilizes classification and clustering techniques
  • Depends on the quality of the data
💡 Common Applications:
Image classification Medicine Voice recognition Spam detection Word processing Social networks Anomaly detection
📊 Example:
  • We have 1,000 emails:

    • 100 are labeled as spam or non-spam.

    900 are unlabeled.

    The model learns from the 100 labeled emails and uses the other 900 to identify patterns and improve its classification.

Reinforcement learning

Reinforcement learning is a branch of machine learning in which an agent learns through trial and error to make decisions within an environment.

Rewards Trial & Error
📌 Key Characteristics:
  • Agent: The AI that makes decisions
  • Environment: The world where it acts
  • State: Current situation of the environment
  • Action: Decision that the agent can make
  • Reward: Feedback received by the agent for its actions
  • Policy: A strategy that determines what action to take
  • Value Function: A function that estimates the expected reward for a given state or action
  • Episode: A complete sequence of actions until it ends
💡 Common Applications:
Video Games Artificial Intelligence Robotics Autonomous Vehicles Finance Healthcare Transportation and Traffic Management
📊 Example:
  • An AI learns to play a video game by trying different moves and receiving rewards for advancing or winning.
  • It is used to teach robots to perform tasks through trial and error.
