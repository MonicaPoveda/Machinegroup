Problem Context

Spam messages can contain characteristics that help distinguish them from legitimate messages. In this application, Logistic Regression is used to analyze two measurable characteristics of a message.

The model predicts whether a message belongs to Class 0 (No Spam) or Class 1 (Spam).

Purpose of the application

Enter the characteristics of a message and use the trained model to obtain a predicted class and its Spam probability.

What problem is being analyzed?

The model classifies messages according to whether they are Spam or No Spam.

What are the input variables?

Suspicious Words and Number of Links are the two independent variables used by the model.

What is the target variable?

The target variable is Spam, with Class 0 representing No Spam and Class 1 representing Spam.

Dataset

The dataset contains 96 records, divided into 76 training records and 20 test records.

Model Information

The application uses a Logistic Regression classifier trained with two independent variables to perform binary classification.

Input Variables (X)
  • Suspicious Words: number of suspicious words detected in the message.
  • Number of Links: number of links contained in the message.
Target Variable (Y)

The target variable is Spam.
