Problem Context

This example analyzes the relationship between Study Hours and Final Grade using Logistic Regression.

The goal is to classify whether a student passes based on their study hours.

X: Study Hours
Y: Grade (0=Fail, 1=Pass)

Code Implementation

# Import libraries
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# Data
data = pd.DataFrame({
    'Study Hours': [10, 15, 12, 8, 14, 5, 16, 7, 11, 13],
    'Pass': [0, 1, 0, 0, 0, 1, 0, 0, 0, 0]
})

X = data[['Study Hours']]
y = data['Pass']

# Train model
model = LogisticRegression()
model.fit(X, y)
Result: The model predicts whether a student passes based on their study hours.
