What Is Logistic Regression?

Logistic Regression is a supervised learning algorithm used mainly for classification problems.

In binary classification, the model predicts the probability that an observation belongs to one of two possible classes.

Core Idea

Logistic Regression converts input information into a probability between 0 and 1 and then uses a classification threshold to determine the predicted class.

Probability and Prediction

The model predicts a probability before assigning a class.

Logistic Regression does not directly produce only Class 0 or Class 1. First, it calculates a probability between 0 and 1. This probability represents how strongly the model associates an observation with the positive class.

Sigmoid Function

The function that converts model output into a probability.

The Sigmoid Function transforms the model's numerical output into a value between 0 and 1.

Sigmoid Equation

P(x) = 1 / (1 + e-(β₀ + β₁x))

The sigmoid function produces an S-shaped curve and maps the model's output to a probability between 0 and 1.

Probability Range Output is always between 0 and 1.
S-Shaped Curve The sigmoid function produces an S-shaped curve.
Transformation Maps the model output to a probability.

Classification Threshold

The threshold converts probability into a final class.

The classification threshold is commonly set to 0.5. It determines whether the predicted probability results in Class 0 or Class 1.

Probability ≥ 0.5 Predicts Class 1

If the predicted probability is equal to or greater than 0.5, the model assigns the observation to Class 1.

Probability < 0.5 Predicts Class 0

If the predicted probability is below 0.5, the model assigns the observation to Class 0.

Example: Probability → Classification
Probability = 0.72

0.72 ≥ 0.5 → Class 1

Probability = 0.30

0.30 < 0.5 → Class 0
