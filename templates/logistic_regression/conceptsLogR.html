What Is Logistic Regression?

Logistic Regression is a supervised learning algorithm used for binary classification problems.

It predicts the probability that an observation belongs to a specific class. The result is a probability between 0 and 1.

Core Takeaway

Logistic Regression transforms input values into probabilities and uses those probabilities to determine the predicted class.

Binary Classification

The model estimates the probability of an observation belonging to a class.

Sigmoid Function

The function that converts model output into a probability.

The Sigmoid Function transforms any real value into a probability between 0 and 1.

Sigmoid Equation

P(x) = 1 / (1 + e-(β₀ + β₁x))

The sigmoid function creates an S-shaped curve and maps the model's output to a probability between 0 and 1.

Probability Range Output is always between 0 and 1.
S-Shaped Curve The sigmoid function produces an S-shaped curve.
Transformation Maps any real value to a probability.

Classification Threshold

The threshold determines the final predicted class.

The classification threshold is typically set to 0.5. It determines whether the predicted probability belongs to Class 0 or Class 1.

Probability ≥ 0.5 Predicts Class 1

When the probability is equal to or greater than 0.5, the model predicts the positive class.

Probability < 0.5 Predicts Class 0

When the probability is below 0.5, the model predicts the negative class.

Example

A probability of 0.72 would be classified as Class 1, while a probability of 0.30 would be classified as Class 0.

Linear vs Logistic Regression

Main differences between both regression algorithms.

Linear Regression predicts continuous numerical values, while Logistic Regression is used to predict categorical classes.

Linear Regression Logistic Regression
Predicts continuous values Predicts categorical classes
Uses a linear function Uses a sigmoid function
Output can be any numerical value Output is a probability from 0 to 1
Evaluation: MSE, R² Evaluation: Accuracy, Precision, Recall
Example: House price prediction Example: Spam email detection
