Problem Context

Diabetes is a chronic disease associated with elevated blood glucose levels and can be identified through the analysis of different clinical and physiological measurements. Therefore, classification techniques can be applied to identify patterns associated with the presence or absence of the disease.

In this application, a Support Vector Machine (SVM) classifier is used to analyze patient data and assign each observation to one of two classes: non-diabetic or diabetic.

Purpose of the Application

The application uses the trained SVM model to classify a new patient observation according to the values entered for the clinical variables.

What Problem Is Being Analyzed?

The problem consists of classifying patient observations according to whether they belong to the diabetic or non-diabetic class.

What Do the Data Represent?

Each record represents a patient observation containing clinical measurements and its corresponding diabetes classification.

What Are the Independent Variables?

The independent variables are Glucose, BloodPressure, BMI and Age, which provide the information used by the classifier.

What Is the Target Variable?

The target variable is Outcome, which represents the class assigned to each patient observation.

What Are the Possible Classes?

The model works with two possible classes: 0 = No Diabetes and 1 = Diabetes.

What Does the Model Classify?

The SVM classifies a new patient observation as belonging to the non-diabetic or diabetic class.

Model Information

The application uses a Support Vector Machine (SVM) with a linear kernel to perform binary classification. The model is trained using four independent variables obtained from the diabetes dataset.

Input Variables (X)
  • Glucose: plasma glucose concentration.
  • BloodPressure: diastolic blood pressure.
  • BMI: Body Mass Index.
  • Age: patient's age in years.
Target Variable (Y)

The target variable is Outcome, which defines the classification assigned to each observation.

0 = No Diabetes1 = Diabetes
SVM Configuration

The classifier uses a Support Vector Machine (SVM) with a linear kernel to separate the two possible classes.

The model is configured with C = 1.0, which controls the balance between classification errors and the separation of the classes.

Before training, the four input variables are standardized using StandardScaler.
